# fat1hkaya.github.io

Personal portfolio of **Fatih Kaya** — Computer Engineering student at Marmara University, focused on SOC, detection engineering and SIEM/SOAR.

🌐 **Live:** https://fat1hkaya.github.io

## What's on the site

- **SIEM-style hero** with a simulated live alert feed
- **Interactive lab topology** of the SOC home lab, with an attack-replay animation
- **Case studies** — directory scanning, SQL injection and RDP brute force, each mapped to MITRE ATT&CK
- **Skills & ATT&CK coverage**, experience timeline and project cards
- **Interactive terminal** — try `help`, `lab`, `detections`, `projects`
- **Turkish / English** toggle

## Tech

A single `index.html`: hand-written HTML, CSS and vanilla JavaScript. No framework, no build step, no external scripts. Served by GitHub Pages from the `main` branch.
